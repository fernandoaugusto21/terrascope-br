# terrascope-br

Brazilian data layers for [Terrascope](https://github.com/a-shygun/Terrascope), packaged as a plugin.

Work in progress. The planned layers use public Brazilian sources: IBGE state and municipal boundaries, INPE fire
hotspots, the IAG-USP seismology catalogue, SP Águas rain gauges and the IAG-USP Chuva Online radar.

Requires a Terrascope build with layer plugin support (entry points `terrascope.layers` and `terrascope.tabs`).
